# ADR-001：移除 CodeFree Provider AgentLabel 路径段提取并依赖前端 Fallback

## 1. 上下文

CodeFree provider（`AgentCodeFree`）的 `AgentLabel` 此前通过 `codefreeAgentLabel` 函数从 agent URI 路径段提取值（如 `spec`、`sdd-dev-engineer`、`explore`）。这些路径段是内部数字员工类型标识符，不是用户可见的显示名称。前端 UI 因此显示 "SPEC"、"SDD-DEV-ENGINEER" 等不友好标签。

前端 `KNOWN_AGENTS` 列表已有成熟的 fallback 机制：`agentLabel(agent, override)` 函数在 `override` 为空时，按 `agent` name 在 `KNOWN_AGENTS` 中查找匹配条目并返回其 `label`。其他 provider（如 `claude`、`codex`）的显示名均由前端管理，parser 层不承担显示名职责。

## 2. 决策驱动因素

- parser 层不应承担显示名职责，显示名属于前端关注点
- agent URI 路径段是内部类型标识符，不应暴露给用户
- 前端已有 `KNOWN_AGENTS` fallback 机制，无需在 parser 层重复实现
- 与其他 provider 的架构保持一致（parser 层不硬编码显示名）

## 3. 备选方案

### 3.1 方案A：移除路径段提取，AgentLabel 留空，前端 KNOWN_AGENTS fallback

- 方案说明：移除 `codefreeAgentLabel` 函数和 `path` 包导入，`AgentLabel` 设为空字符串；在 `KNOWN_AGENTS` 新增 `codefree` 条目，label 为 "CodeFree"
- 优点：parser 层职责清晰；显示名由前端统一管理；与现有架构一致；移除 `path` 依赖减少耦合
- 缺点：需要同时修改 parser 和前端两个文件
- 风险：若前端 fallback 逻辑假设不成立，可能显示 agent name 而非 "CodeFree"（已确认假设成立）

### 3.2 方案B：在 parser 层硬编码 "CodeFree" 作为 AgentLabel

- 方案说明：将 `codefreeAgentLabel` 函数的返回值改为固定字符串 "CodeFree"
- 优点：仅修改一个文件，变更范围最小
- 缺点：parser 层承担显示名职责，与现有架构不一致；显示文案固化在 Go 代码中，修改显示名需要重新编译；其他 provider 的 label 由前端管理，此处成为例外
- 风险：显示名变更需要修改 Go 代码并重新发布

## 4. 决策

选择方案A：移除 `codefreeAgentLabel` 函数和 `path` 包导入，`AgentLabel` 设为空字符串；在 `KNOWN_AGENTS` 新增 `codefree` 条目，label 为 "CodeFree"。

## 5. 决策理由

方案A 与现有架构一致：所有 provider 的显示名均由前端 `KNOWN_AGENTS` 管理，parser 层不硬编码显示名。方案B 会让 CodeFree 成为唯一在 parser 层硬编码显示名的 provider，引入架构不一致。方案A 的风险（前端 fallback 假设）已通过代码审查确认不成立：`agentLabel()` 函数在 `override?.trim()` 为 falsy 时确实按 name 查找 `KNOWN_AGENTS`。

## 6. 后果

### 6.1 正面影响

- parser 层职责清晰，不承担显示名职责
- 前端统一管理所有 provider 的显示名
- 移除 `path` 包依赖，减少 parser 层耦合
- 不再在 UI 中暴露内部数字员工类型标识符

### 6.2 负面影响与代价

- 需要同时维护 parser 和前端两个文件的变更一致性
- 若未来 CodeFree provider 需要在 parser 层提供动态显示名，需要重新评估此决策

## 7. 实施与验证

- 实施要求：移除 `internal/parser/codefree.go` 中的 `codefreeAgentLabel` 函数和 `path` 包导入；在 `frontend/src/lib/utils/agents.ts` 的 `KNOWN_AGENTS` 列表新增 `codefree` 条目
- 验证方式：`go vet ./internal/parser/` 无未使用导入错误；`TestLoadCodeFreeSession_UserAndAssistant`、`TestCodeFreeProvider_Parse` 验证 AgentLabel 为空字符串；前端代码审查确认 `KNOWN_AGENTS` 包含 `codefree` 条目且 `agentLabel("codefree")` 返回 "CodeFree"
- 回滚条件：变更后 CodeFree 会话在 UI 中显示异常或 parser 测试失败
